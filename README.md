# Make Yes Safer

An interactive control stress test by Dharshun Sri Dharan / AI4U. Compare the consequences of the same control design across legitimate supplier bank changes and attempted payment diversions.

All scenarios, facts, timings and outcomes are fictional. AI helped prepare the scenarios and explanations in advance. The page applies deterministic rules to these prepared cases; it makes no live AI calls and does not generate or analyse arbitrary new scenarios.

Six cases are available initially. Two further prepared challenges expose assumptions behind an apparently successful design. The controls use specified evidence and timings; the fictional underlying truth is used afterward to label outcomes.

No actual payments, business systems or customer records are connected. There are no uploads, analytics or external dependencies. Choices stay in the page, and the downloadable brief is generated on the visitor's device.

This is a thought experiment, not a measure of real control effectiveness, AI accuracy, event frequency, financial benefit or loss. The selected cases cannot establish those outcomes.

Serve this directory with any static HTTP server. No build step is required. The existing repository name and Pages URL are retained for continuity.
