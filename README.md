# The Unseen Organisation

An interactive thought experiment by Dharshun Sri Dharan / AI4U about connecting fragmented organisational knowledge.

Northstar Workspace, all source records and all metrics are fictional. The case and its AI-assisted analysis were prepared in advance. There are no live language-model calls, uploads or analytics. Interactions apply predefined interpretations to the selected evidence; they do not analyse arbitrary new text or establish AI accuracy, customer demand or financial return.

Open index.html through a static HTTP server. This site has no build step or external dependencies.
